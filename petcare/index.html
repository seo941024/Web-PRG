금지 음식 & 응급 처치

모르고 주면 위험해요. 미리 알아두세요

❓

검색 결과

자주 찾는 검색어

🍇 포도 🍫 초콜릿 🧅 양파 🌸 백합 🥑 아보카도 🥕 당근

⛑️ 응급 상황 대처 가이드

🚨 기도 이물질 (막혔을 때)

  1. 강아지를 뒤에서 안고 두 손을 배 아래 모아 쥡니다
  2. 명치 약간 위를 빠르게 4~5회 위로 밀어 올립니다
  3. 이물질이 나오면 제거, 안 나오면 즉시 병원 이동
  4. 의식이 없으면 CPR 시작 후 119에 연락하세요

💊 독성 물질 섭취

  1. 섭취한 물질과 양을 메모하거나 사진 촬영
  2. 구토는 절대 유도하지 마세요
  3. 즉시 동물병원 또는 동물 중독 신고센터에 연락
  4. 동물 중독 상담: 1670-0119

🔥 화상 / 고열

  1. 흐르는 차가운 물로 15~20분간 식혀줍니다
  2. 얼음은 절대 직접 대지 마세요
  3. 여름 차 안에 두면 10분 안에 위험 — 절대 금지
  4. 열사병 의심 시 몸을 적신 수건으로 감싸고 병원

🩹 출혈 / 상처

  1. 깨끗한 천이나 거즈로 5~10분간 압박
  2. 상처 주변 털을 제거하면 소독이 쉬워집니다
  3. 사람용 소독약(과산화수소) 사용 금지
  4. 지혈이 안 되면 즉시 동물병원으로
