# 해골용사 (SKULL YUUSHA)

바닐라 JavaScript와 HTML5 Canvas 2D로 제작한 로그라이트 액션 플랫포머. 죽으면 처음부터 다시 시작하지만, 영구 강화로 조금씩 강해지며 8개 직업과 다양한 유물·보스를 즐길 수 있습니다.

## 플레이 방법

브라우저에서 `index.html`을 열면 바로 실행됩니다. (별도 빌드·서버 불필요)

### 조작키

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Z | 대쉬 |
| X | 점프 (2단 점프 가능) |
| C | 평타 |
| ↓ + C | 강하 공격 |
| Shift | 스킬 사용 |
| V | 가드 / 패링 |
| M | 음소거 |

## 직업 (8종)

| 직업 | 특징 |
|---|---|
| 검사 | 밸런스형. 콤보 마지막 타에 섬광 강타 |
| 도적 | 초고속 쌍단검. **보스·엘리트 학살자** — 콤보 유지로 치명타율 상승 |
| 마법사 | 원거리. 평타로 MP를 모아 강력한 광역 스킬(아크틱 할로우) |
| 버서커 | 느리지만 한 방이 강한 고체력 전사. 처치 시 광기 스택 |
| 발키리 | 8발 사격 후 재장전. 빠른 연사와 크루 소환 |
| 성기사 | 망치+방패 탱커. 패링 특화, 방어력이 곧 공격력 |
| 혈귀 | 피해를 받을수록 강해지는 흡혈 근접. HP를 태우는 혈기격 |
| 조커 | 카드 투척 원거리. 치명타 45% / 치명타 피해 500% 특화 |

> 혈귀·조커는 모든 직업을 해금한 뒤 도전할 수 있는 고난도 최종 직업입니다.

## 시스템

- **유물**: 스테이지 진행 중 획득하는 일회성 강화. 공격력은 %로 적용되어 모든 직업에 공평하게 적용됩니다.
- **다크 퀴츠**: 런을 넘어 유지되는 재화로 영구 강화·해금 구매.
- **스테이지 & 보스**: 각 월드마다 고유 보스와 점증하는 난이도 곡선.
- **전투감**: 패링, 가드 브레이크, 콤보, 스태미너 관리 등 액션성 중심 설계.

## 기술 스택

- 순수 JavaScript (프레임워크 없음)
- HTML5 Canvas 2D (내부 해상도 640×360, 2× 업스케일)
- Web Audio 기반 효과음 / BGM
- 외부 의존성 없음
